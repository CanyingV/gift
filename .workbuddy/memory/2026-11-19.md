## 多平台打包（apk / exe / dmg）

- 用户选择「保留 Python 后端」，三端统一走 GitHub Actions 云端构建。
- 重构 `app.py`：服务启动移入 `run_server()`，导入不再自启动；`BASE`/`DB` 支持 `GIFT_BASE_DIR`/`GIFT_DB_PATH` 环境变量覆盖，供桌面壳和 Android 复用。已验证环境变量方式启动后 API 与导出正常。
- 桌面端新增 `desktop.py`（pywebview 原生窗口 + 随机端口本地服务，数据库落到用户可写目录，首次从随包种子复制）+ `desktop.spec`（PyInstaller：Windows 出 exe，macOS 出 app bundle 再转 dmg）。
- Android 工程在 `android/`：Kotlin DSL，版本组合 Chaquopy 17.2.0 + AGP 9.5.1 + Gradle 9.6（官方验证组合，Chaquopy 12.0.1 起开源免费）。`syncAssets` 任务构建前从项目根目录同步 app.py/index.html/gift；`MainActivity.java` 解包 assets 到私有目录后调用 Python `mobile_entry.start()` 启动本地服务，WebView 指向 127.0.0.1 随机端口。Gradle wrapper 从官方 demo 复制。
- CI 在 `.github/workflows/build.yml`：workflow_dispatch + v* tag 触发，三个 job 分别产 exe/dmg/apk 并上传 artifact；README 补了完整推送与下载步骤。
- 验证：py_compile、XML 解析、桌面入口初始化与端口分配、环境变量方式后端 API/导出均通过。Android/Windows/macOS 的实际安装包需在 GitHub 云端首次构建（本机无 Java/SDK）。
